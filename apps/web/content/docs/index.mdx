title: Correct by Design
description: A code-first design system where correct UI is the default output.
---

Correct by Design packages DTCG design tokens and React components so that the
right styling, accessibility, and behaviour are the **default output** — not
something a per-component review has to enforce.

## What's here

- **Tokens** — a Clean Slate palette, an elevation scale, radius, and an Inter +
  JetBrains Mono type system, all rebindable per theme.
- **Components** — grouped by what they are for (actions, forms, display,
  navigation, overlays, layout), each documented with live, interactive previews
  on the next pages.

These docs are built with the same components and tokens they describe — the
chrome you're reading is itself correct by design.
